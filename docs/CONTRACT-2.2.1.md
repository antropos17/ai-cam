## A1 — параметризация входа поиска

### Состав

- Ассет `DivergenceSettings` как источник настроек: поле ассета в окне;
  пусто = дефолты.
- Редактируемый ε-диапазон поверх источника. Приоритет источников:
  **правка окна > ассет > дефолты**.
- Цель из dropdown существующих тел; ось; стратегия; шаги.
- Валидация fail-closed по таблице ниже: кнопка запуска disabled + причина
  рядом с полем. Никаких silent clamp и молчаливых сбросов.
- Разделение ролей ассет / окно / хост.
- Источник и эффективные значения (floor/ceiling) — в manifest
  (`settingsSource`) и в строку результата.
- Персистентность через `SessionState`; ассет — по GUID.
- Смерть `CreateDefault()` внутри раннера — grep-проверка, что путь
  построения настроек ровно один.
- Ввод в мм, хранение в метрах полной точности, invariant culture.
- Новые тесты: границы валидации (1e-6 м, 1 м, отношение 1.001, шаги ≥ 1)
  и приоритет источников.

### Таблица валидации (тексты причин — verbatim, это UI-литералы)

| Поле | Правило | Причина при нарушении |
|---|---|---|
| ε нижняя | конечное, ≥ 1e-6 м (0.001 мм) | «ниже гейта воспроизводимости 1e-6 м эффект неотличим от шума измерения» |
| ε верхняя | конечное, > нижней, ≤ 1 м | «возмущение крупнее 1 м не является малым» |
| верх/низ | отношение ≥ 1.001 | «диапазон вырожден для 12-точечной лестницы» |
| Шаги | целое ≥ 1, без молчаливого сброса к 32 | «число шагов должно быть положительным» |
| Цель | dropdown существующих тел — невалидное невыбираемо | — |
| Ассет | назначен, но поле невалидно / ассет удалён | причина называет ассет и конкретное поле; без тихого отката к дефолтам |

## A3 — нормализация sceneScore

- Per-step score меняется с суммы по телам на **max** per-body weighted norm.
- `SceneScoreThreshold` ре-ратифицируется по измерению шума/дивергенции башни.
- Сдвиг закреплённых чисел башни = STOP и адъюдикация.
- Запрет автоудаления score-половины гейта: даже если измерение покажет, что
  она никогда не решает, удаление НЕ автоматическое — отдельная адъюдикация
  над измеренными данными.

## A2 — захват произвольной сцены (sub-stage)

- Определение чистой сцены и три исхода захвата: captured /
  excluded-безопасно (бесконтактные тела) / fail-closed с per-object
  причинами.
- Примитивные коллайдеры Box + Sphere; ратифицировано: `Size` сферы =
  диаметр.
- Кинематические тела замораживаются в static; при Animator — предупреждение
  распространяется в окно И в вердикт результата И в manifest/evidence
  (потребитель улик обязан видеть каверзу без окна).
- Неподдерживаемые контактоспособные шейпы / джойнты / shear ⇒ fail-closed
  захват с причинами по объектам.
- Детерминизм захвата: stable ID = hierarchy path + sibling index;
  id↔name map и capture hash в manifest.
- Отчёт захвата в окне + секция `sceneCapture` в manifest.
