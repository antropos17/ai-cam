# Blockclose

Before declaring any block done, verify each item below and show the evidence for it. An item without evidence shown is not done.

1. Full gate green, with the exact EditMode and PlayMode counts.
2. Tower and domino reference numbers bit-identical to the pinned values, shown side by side.
3. `docs/STATUS.md` updated with the block outcome.
4. `docs/CODEMAP.md` updated per the block-close precedent.
5. `git status` clean, with no accidental files (events.jsonl-class leaks).
6. All commits pushed, or explicitly reported as local.
7. Any PENDING items named, together with where they moved.
