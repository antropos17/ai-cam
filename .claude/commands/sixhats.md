# Sixhats

$ARGUMENTS is the decision to analyse. This command covers product and business decisions only: positioning, pricing, demo composition, landing, marketing. If $ARGUMENTS is an engineering decision governed by a ratified contract, say so and stop — do not run the modes.

Run the six thinking modes strictly in this order, without mixing them:

1. FACTS — only known data and named gaps.
2. FEELINGS — gut read, no justification.
3. RISKS — devil's advocate, specific.
4. BENEFITS — only upside.
5. IDEAS — unbounded alternatives, including ones that contradict the current plan.
6. VERDICT — one recommendation, not a menu, plus exactly three first steps.

Answer in Russian.
